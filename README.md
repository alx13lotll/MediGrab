# MediaGrab (open source, MIT)
Téléchargeur YouTube / TikTok basé sur yt-dlp + ffmpeg (youtubedl-android).
MP4 (360p→2160p), MP3, WAV, extrait GIF, affiche JPG, statistiques de la vidéo.
Build : push sur GitHub → onglet Actions → artifact "MediaGrab-apk" → installer l'APK.
Astuce : depuis TikTok/YouTube, "Partager" → MediaGrab pré-remplit le lien.
