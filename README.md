# MediGrab
MediaGrab : colle un lien ou utilise Partager depuis TikTok/YouTube. Détection auto de la plateforme, aperçu (titre, auteur, durée, vues, likes, date) sans lire la vidéo. Télécharge en MP4 (360p–2160p), MP3, WAV ou GIF. Affiche JPG en option. Fichiers dans Téléchargements/MediaGrab. Bouton MAJ yt-dlp.
